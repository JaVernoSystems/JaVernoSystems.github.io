by Javerno Systems

WHY BOXDOCS EXISTS
BoxDocs was born out of a familiar problem: knowing that you own something, knowing it’s packed away safely… and having absolutely no idea which box it’s in. Holiday decorations, spare cables, keepsakes, the infamous “junk drawer” box; at some point the answer becomes “It’s in a box somewhere.”

BoxDocs exists to turn that vague certainty into a concrete answer. Instead of opening ten boxes or rebuying something you already have, you can look it up, see the box, and go straight to it.

WHAT BOXDOCS DOES
• Creates boxes with a unique tag and optional title
• Tracks item lists per box
• Saves all changes immediately (there is no Save button)
• Supports searching within a single box and across all boxes
• Allows printing box labels and contents lists

BoxDocs is designed to be simple, offline, and dependable.

HOW TO USE BOXDOCS (QUICK START)

Create a box
Enter a short tag (for example, OFFICE or HOLIDAY) and an optional title, then click Add Box.

Select a box
Click a box from the list on the left to view or edit its details.

Add items
Type an item name and click Add Item. Changes are saved automatically.

Find items
• Use “Search items in this box” to filter items within the selected box.
• Use Global Search to find items across all boxes and jump directly to the box that contains them.

Edit or clean up
• Rename boxes or update titles at any time.
• Delete individual items or entire boxes when they’re no longer needed.
• Use Undo to recover a recently deleted box.

Print labels or contents
• Print a box label to attach to the physical container.
• Print a contents list to keep with the box or for reference.

That’s it. There’s nothing to save. Every change is stored as it happens.

DATA STORAGE
All data is stored locally on your computer in plain text.
No accounts, no cloud storage, and no internet connection are required.

KNOWN LIMITATIONS (BETA)

• No automatic backups
Data is stored locally only. It’s recommended to periodically back up the data file manually.

• No multi-user support
BoxDocs is designed for a single user on a single machine.

• No cloud sync
Boxes and items do not sync across devices.

• Limited undo
Undo currently applies only to the most recent box deletion.

• Printing is single-page oriented
Very long item lists may not paginate cleanly in the current beta.

• UI polish is ongoing
Some interactions may feel utilitarian rather than refined.

These limitations are known and intentional for the beta release.

BETA NOTES
This is a beta version.
Features may evolve, and behavior may change based on feedback.

BoxDocs isn’t a corporate product. It’s a practical tool built to answer one simple question:

“Which box is that in?”

If it helps you avoid digging through storage or buying something you already own, it’s doing its job.
